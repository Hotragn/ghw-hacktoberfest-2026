Contributor-readiness

A place to start, or a trail with the signs missing.

Nine signals add up to 100. A high score means a newcomer can find the door, a license, a starter issue, and a maintainer who writes back. It is not a judgment of the code.

  1. 85+ Ready for a first contribution
  2. 70+ Welcoming, with a few gaps
  3. 50+ Possible, but you will do some digging
  4. 30+ Thin onboarding

Scores come from the public GitHub REST API. Share a result with ?repo=owner/name. Open this folder through a local server so the browser can call the API.
